# S6 Takeaway Kit — Control Plane & Operationalization

This kit supports a facilitator-led, customer-operated S6 activity: assess
input quality, explicitly normalize a registry, run a read-only reconciliation,
triage findings, discuss maturity lift, and make a closeout and operating-cadence
decision. It does not export an undocumented service API, infer a schema, write
registry data, or ship customer evidence.

Use [`runbook.md`](runbook.md) for the required input schemas, read-only
reconciliation, S0 re-score, closeout handoff, and safe blocker pathways.
