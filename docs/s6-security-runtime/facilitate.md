# Facilitate the decision

| Phase | Time | Focus |
|---|---:|---|
| Confirm safety | 15 min | Reconfirm the non-production route and reviewers. |
| Review | 35 min | Correlate the proof ID with gateway telemetry. |
| Decide | 40 min | Accept, defer, or reject the proof. |

Ask: **“Can reviewers find this request in gateway evidence?”**
