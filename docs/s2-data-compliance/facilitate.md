# Facilitate the decision

| Phase | Time | Focus |
|---|---:|---|
| Set scope | 10 min | Confirm the path and investigation owner. |
| Review | 35 min | Separate coverage, no-result, and capability gaps. |
| Decide | 45 min | Choose no change, report-only review, or a blocker. |

Ask: **“Where can sensitive data leave this path?”**
