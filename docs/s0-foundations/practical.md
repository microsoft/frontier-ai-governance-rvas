# Practical workshop: first governance backlog

**Customer owner:** Governance lead. **Timebox:** 45 minutes. Work only in the
customer's approved records system.

1. Copy the blank scorecard and technical decision record; score one bounded
   pilot or mark unsupported questions as unknown.
2. Run the offline scorer against the customer copy. It ranks gaps; it does not
   make a decision.
3. Default: use the existing customer governance forum and backlog. An exception
   needs a named sponsor, reason, risk owner, and review date.
4. Ask: **“Do we approve, defer, reject, or route the first governance backlog
   item?”** Record one result, owner, evidence reference, acceptance criterion,
   and target date.
5. Hand the item to the named customer governance, architecture, identity, or
   data owner. This workshop changes no customer system and approves no
   production use.
