# AI Governance Platform

AI Governance Platform is a facilitator-led S0-S13 curriculum for customer decisions on ownership, data, platform controls, assurance, and operation.

Start with [About AI Governance Platform](start/understand-rvas.md), then use [Plan the engagement](start/plan-engagement.md) to triage the proposed use case before running [S0 · Foundations & Governance Operating Model](s0-foundations/index.md).

The curriculum is organized into four phases:

1. **Govern (S0-S2):** operating model, agent identity and authority, and data governance.
2. **Establish (S3-S5):** enterprise platform trust boundaries, engineering admission standards, and API/tool/MCP governance.
3. **Assure (S6-S8):** runtime security, quality and release evidence, and approved adversarial testing.
4. **Operate (S9-S13):** control-plane stewardship, in-process governance where it applies, operating review, LLM operations, and portfolio improvement.

Use [Facilitate a co-delivery working session](delivery/facilitation-pattern.md) for the 90-minute customer-led method. Use the [Governance capability guide](reference/governance-capability-guide.md) for capability context and [Platform technical guide](reference/platform-technical-guide.md) for platform evidence and ownership boundaries. Use [Quality, cost, latency, and rollout governance](reference/quality-cost-latency-guide.md) for cross-session decision-record guidance.

The S0 roadmap selects sessions and dependencies. Pre-S0 triage only confirms that the use case is bounded enough to start, identifies obvious safety or supplier-governance blockers, and routes work to customer records. S10 runs only where an in-process tool-call boundary exists; decision authority, human approval, change approval, evidence retention, incident routing, rollback, decommissioning, and legal or compliance conclusions remain with the customer.
