# Frontier AI Governance - RVAS AI Governance

RVAS AI Governance is a facilitator-led, S0-S12 curriculum for establishing,
assuring, operating, and continuously improving AI-agent governance in a
customer's environment.

Start with [About RVAS AI Governance](start/understand-rvas.md), then use
[Plan the engagement](start/plan-engagement.md) before running
[S0 · Foundations & Governance Operating Model](s0-foundations/index.md).

The curriculum is organised into four phases:

1. **Govern (S0-S2):** operating model, agent identity/authority, and data
   governance.
2. **Establish (S3-S5):** enterprise platform trust boundaries, engineering
   admission standards, and API/tool/MCP governance.
3. **Assure (S6-S8):** runtime security, quality/release assurance, and
   adversarial testing.
4. **Operate (S9-S12):** control-plane stewardship, in-process governance
   where applicable, operating review, and portfolio improvement.

Use [Facilitate a co-delivery working session](delivery/facilitation-pattern.md)
for the 90-minute customer-led method. Use the
[Governance capability guide](reference/governance-capability-guide.md) for
capability context and [Platform technical guide](reference/platform-technical-guide.md)
for platform evidence and ownership boundaries.

The S0 roadmap determines which sessions are in scope and their dependency
order. S10 is applicable only where an in-process tool-call boundary exists.
All sessions preserve customer decision authority and the customer-owned change
process.
