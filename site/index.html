Pre-work

Clear the pre-work before Session 1.

Each item below blocks hands-on work at the first deployment. Model quota and Purview or Agent 365 entitlements are not needed on day one, but approval runs long, so raise those requests while you work through this list.

Environment

Dedicated sandbox

Use an approved subscription and register the required resource providers.

Source control

Customer-owned repository

Prepare the repository that will keep implementation files and decisions.

Access

Roles at the exact scope

Session 1 needs Contributor on the sandbox scope plus permission to run deployment what-if there. Later sessions add their own time-bound roles.

Region

Delivery region approved

Check the region against the Foundry capabilities planned for the wider engagement.

Scenario

One bounded use case

Use an internal policy assistant that starts with one read-only API tool and gains a governed MCP path and one write action it must refuse as later sessions add them.
