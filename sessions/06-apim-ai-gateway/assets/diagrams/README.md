# Session diagrams

Store one editable source and its rendered SVG for each diagram here. Use either a `.drawio` or
`.excalidraw` source, never both for the same SVG. Publish and reference only the SVG with a
descriptive filename and meaningful alt text in the guide and deck.

Use the bundled Microsoft service icons without recoloring, cropping, rotating, or
distorting them. Keep product names visible near their icons.

Generate Draw.io sources from YAML in `.drawio-tmp/`, validate the layout, and inspect the SVG
before adding it here.
