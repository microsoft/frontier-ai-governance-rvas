# Diagrams

Keep one editable source and its rendered SVG together. Use either `.drawio` or `.excalidraw`,
never both for the same SVG. Reference the SVG from the guide or deck with meaningful alt text.

Use the bundled Microsoft service icons without recoloring, cropping, rotating, or distorting them.
Keep product names visible near their icons. Generate Draw.io sources from YAML in `.drawio-tmp/`,
validate the layout, and inspect the SVG before adding it here.
