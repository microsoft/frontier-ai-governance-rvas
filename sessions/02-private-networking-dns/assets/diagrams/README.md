# Session 02 diagrams

Keep one editable source and its rendered SVG for each diagram. Use either `.drawio` or
`.excalidraw`, never both for the same SVG. `private-network-topology.drawio` shows the service
topology, and `public-access-cutover.excalidraw` keeps the guarded cutover sequence.

The diagrams use the endpoint aliases, required FQDN placeholders, DNS zones, and state fields from
the Session 02 artifacts. They contain no customer topology, addresses, or identifiers.
