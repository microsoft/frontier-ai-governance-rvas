# Session diagrams

`controlled-promotion-flow.excalidraw` is the editable source for the release flow diagram.
Its checked-in SVG is the rendered copy used by the deck and generated course page. Edit the
Excalidraw file first, then render and inspect both outputs before committing them.

Use the bundled Microsoft service icons without recoloring, cropping, rotating, or
distorting them. Keep product names visible near their icons.
