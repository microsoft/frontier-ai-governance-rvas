# Session diagrams

- `identity-boundary.excalidraw` is the editable source for the identity-path decision tree.
- `identity-boundary.svg` is the rendered deck asset.
- `oidc-trust-scope.excalidraw` is the editable source for the GitHub OIDC trust and Azure role-scope visual.
- `oidc-trust-scope.svg` is the rendered implementation-guide asset.

Edit the `.excalidraw` files, then render the matching SVGs. Both visuals use the project palette
and generic coordinates. They contain no customer topology or identifiers.
