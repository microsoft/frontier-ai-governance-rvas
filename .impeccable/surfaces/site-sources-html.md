# Research source ledger

## Scope and mode

- Target: `site/sources.html`
- Mode: Read
- Scope: the dedicated research and primary-source index for the public GitHub Pages site.

## Audience, job, and action

Readers who need to verify a product, platform, standards, or project claim can scan the full source ledger without interrupting the program narrative. The primary action is to open a source. The secondary action is to return to the program.

## Content authority

The ledger combines the authoritative sources recorded in the session manifests. Keep publisher and access-date metadata accurate. Do not add unsupported claims, summaries, or customer outcomes.

## Constraints

The page shares the static header, footer, typography, responsive behavior, keyboard access, reduced-motion handling, and print support used by the home page. The research date belongs in this page's introduction, never in a global header pill.

## Chosen direction

RVAS remains the visual authority: navy-to-blue introduction, RVAP logo, Aptos/Outfit and Inter typography, JetBrains Mono metadata, pale blue-white surfaces, and restrained dividers.

## Memorable moment

A short navy introduction makes the page feel connected to the program, then gets out of the way so the two-column source ledger can do the work.

## Unresolved decisions

The repository has no confirmed public URL. All navigation remains relative for GitHub Pages.
