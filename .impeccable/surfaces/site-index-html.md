# Public reference home

## Scope and mode

- Target: `site/index.html`
- Mode: Read
- Scope: the public GitHub Pages landing and reference surface.

## Audience, job, and action

Enterprise decision-makers and hands-on practitioners must understand the implementation-first operating model, then explore the 15-session path without losing phase, duration, dependencies, outcomes, retained outputs, or result checks. The primary action is to browse the program; the secondary action is to inspect the target architecture and implementation principles.

## Content authority

Use `PRODUCT.md` for the program model and each session manifest for scope, dependencies, outcomes, retained outputs, and dated sources. Do not fabricate customer outcomes or imply that templates confirm deployed controls.

Standard mode is the default: implement one control, retain production-shaped outputs, run one observable check, and document rollback. Extended mode needs a recorded reason and adds an intended-path check, a blocked or failure-path check, and a delivery-owner checkpoint. Neither mode adds a lab package or disposable demonstration resources. Automation is conditional.

The RVAS repository is visual authority only. Its S0-S12 curriculum and page claims are out of scope for this site.

## Constraints

The surface is static HTML, CSS, and JavaScript, deployable without a build step through GitHub Pages. It must work with keyboard navigation, reduced motion, narrow screens, and JavaScript unavailable. Time-sensitive claims keep their caveats. The full source ledger and research date live on a dedicated sources page rather than in the home page or global header.
