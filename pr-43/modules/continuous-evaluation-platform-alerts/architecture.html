Architecture at a glance#

The Foundry account emits platform logs and metrics. The diagnostic setting sends them to the approved Log Analytics workspace. Azure Monitor metric alerts watch three operator-owned signals: 429 throttling, time to last byte, and token volume. The action group routes those alerts.

The Foundry project stores monitoring and evaluation data in Application Insights. The continuous evaluation script creates an evaluation from the recorded evaluator list, then creates or updates a rule for RESPONSE_COMPLETED events from the governed agent. The rule uses maxHourlyRuns as the sampling cap.

Application Insights, Log Analytics, and Foundry remain authoritative for live telemetry and evaluation runs. The repository records the intended state and the owner decisions that live services do not reconstruct later.

Architecture guidance#

Use Monitor agents with the Agent Monitoring Dashboard for the continuous evaluation rule, Application Insights dependency, preview status, and Foundry User role requirement.

Use Monitoring data reference for Azure OpenAI for the metric names, dimensions, token metrics, throttling signal, and latency guidance.

Use Diagnostic Settings in Azure Monitor for diagnostic setting behavior and Log Analytics as a destination for resource logs and platform metrics.
