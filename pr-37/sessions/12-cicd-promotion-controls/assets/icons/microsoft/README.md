# Microsoft service icons

These SVG files are copied from official Microsoft icon packs for use in architecture diagrams, implementation briefings, and documentation.

Sources:

- Azure Architecture Icons: https://learn.microsoft.com/en-us/azure/architecture/icons/
- Microsoft Entra architecture icons: https://learn.microsoft.com/en-us/entra/architecture/architecture-icons
- Microsoft Power Platform icons: https://learn.microsoft.com/en-us/power-platform/guidance/icons
- Microsoft 365 architecture icons and templates: https://learn.microsoft.com/en-us/previous-versions/microsoft-365/solutions/architecture-icons-templates

Usage constraints from the Microsoft source pages apply. Do not crop, flip, rotate, distort, recolor, or repurpose these icons. Keep product names visible near icons when they appear in the site.
