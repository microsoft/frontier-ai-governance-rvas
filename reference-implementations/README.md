# Reference implementations

This area holds non-production reference implementation packages that future
labs can adapt. Use it for cross-session patterns that combine infrastructure,
policy, evaluation, dashboard, agent, and runbook assets.

Reference implementations are reusable starting points. They do not prove that a
customer control is deployed, operating, approved, or production-ready.

## Boundary

- Keep customer identifiers, tenant configuration, credentials, prompts,
  outputs, telemetry exports, screenshots, and evidence payloads out of this
  repository.
- Store customer evidence in the customer's approved records system.
- Treat every package here as a reference until the customer validates it in
  their own environment and change process.
