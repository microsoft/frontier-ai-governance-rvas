# Policy skeletons

This area groups policy assets used by implementation labs. Policies here are
reference starting points until a customer reviews, tests, and approves them in
their own process.

Use subfolders for policy surfaces:

- `azure-policy/` for Azure Policy definitions, initiatives, and assignment
  examples.
- `apim/` for Azure API Management policy fragments and examples.

Do not store customer policy exports, live configuration, or enforcement proof
in this repository.
