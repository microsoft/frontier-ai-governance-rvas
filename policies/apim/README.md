# API Management policy skeletons

Use this folder for future Azure API Management policy fragments and examples
for AI gateway, prompt filtering, correlation, throttling, and tool/API control
patterns.

Each policy asset should state:

- session and maturity level;
- inbound, backend, outbound, or on-error placement;
- required named values or managed identity assumptions;
- non-production smoke test;
- telemetry and evidence references the customer retains.
