# Bicep skeletons

Use this folder for future Bicep modules that support non-production AI
governance implementation labs, such as landing-zone checks, monitoring
resources, gateway proof scaffolds, or policy assignment examples.

Every Bicep asset should document:

- intended session and maturity level;
- required roles and deployment scope;
- parameters that must be supplied by the customer;
- validation command;
- evidence references the customer should retain outside this repository.
